# Чиж-Авто — React flagship preview

Неофициальный демонстрационный проект для компании Чиж-Авто (Краснодар). Не является официальным сайтом.

## Архитектура
- React 19 + Vite 6, Motion for React, Embla Carousel, Lucide React, адаптивная CSS-система.
- `src/main.jsx` — экраны, маршруты, интерактивность и обработка обращений.
- `src/style.css` — индивидуальная визуальная система, мобильные режимы, клавиатура и reduced motion.
- `src/data/catalog.js` — проверенные группы услуг, фотографии и кейсы из источников Чиж-Авто.
- `src/data/snapshot.json` — сборочный индекс дополнительных официальных материалов.
- `scripts/sync-official.mjs` — ограниченный доменом chizhavto.ru сбор актуальных публичных данных; сохраняет fallback, если сайт недоступен.
- `tests/site.spec.js` — e2e-проверки кликов, навигации, фильтров, карточек, формы, видео, мобильного меню.
- Размещение: одна GitHub Pages публикация всего `parsing`, путь `/parsing/chizh-avto/`.

## Локальный запуск
```bash
cd chizh-avto
npm install
npm run check:static
npm run check:factual
npm run sync:official
npm run dev
npm run build
npx playwright install chromium
npm run test:e2e
```

## Как работает публикация
Публикация через `/.github/workflows/deploy-pages.yml`. Для этой папки Actions устанавливает зависимости, по возможности собирает каталог с официального сайта, создаёт Vite dist и выполняет браузерные e2e-тесты. Только после успешной проверки `dist` попадает в `_site/chizh-avto/`. Остальные сайты берутся из собственных каталогов и не изменяются.

## Функциональные сценарии
- Навигация по страницам /#/services, /#/projects, /#/prices, /#/offers, /#/about, /#/contacts.
- Каталог: фильтрация, раскрытие и закрытие категории, переход к исходной подуслуге и предварительно заполненное обращение.
- Портфолио: Embla свайпы и стрелки с disabled-состояниями; каталог проектов с поиском, открытием/закрытием просмотра.
- Прайс: поиск, показать всё/свернуть, ссылки на официальный источник и таблицы из публичного каталога.
- Видео: плеер компании + запасная ссылка на официальный YouTube-канал.
- Форма: валидация, подбор услуги из перехода, составление письма на подтверждённый адрес или копирование текста; приложение само не хранит персональные данные и не подтверждает запись.
- Звонок, email, маршруты и официальные страницы открываются через валидные адреса.

## Проверенные источники и ограничения
- https://chizhavto.ru/ — компания, все 12 основных групп услуг.
- https://chizhavto.ru/services/ — полный каталог, включая подуслуги.
- https://chizhavto.ru/projects/ — проекты и оригинальные фотографии.
- https://chizhavto.ru/prices/ — прайс, включая разные классы автомобилей.
- https://chizhavto.ru/shares/ — акции; даты без года не трактовать как действующие.
- https://chizhavto.ru/reviews/ — отзывы.
- https://chizhavto.ru/company/ — история, профиль, документы.
- https://chizhavto.ru/contacts/ — телефоны, часы работы, Жлобы 115 и Каляева 89.
- https://www.youtube.com/@chizhauto — официальный канал компании.

**Важно:** Изображения внешне загружаются с `chizhavto.ru`, а не из стоков. Права на фото, видео, логотип и содержание принадлежат их владельцам. До коммерческого запуска согласовать права, проверить цены, тексты и правомерность обработки обращений. Демонстрационная форма не является CRM и не отправляет данные на сервер. Возможность собрать абсолютно все исторические публикации на оригинальном сайте не гарантирована; для полного каталога предусмотрены прямые ссылки на оригинал.
