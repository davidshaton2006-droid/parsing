## Дизайн
Отличается от предыдущих GT Service / Alfa Auto / RIA Service:
- позиционирование как установочный и тюнинг-центр вместо обычного СТО;
- визуальная система: угольный #0c0e0f, разогретый жёлто-янтарный #ffb02e, светлый #f2f0e9, жёсткая плотная Unbounded для заголовков + Golos Text для интерфейса;
- композиция: полноэкранная автосъёмка, крупная типографика, асимметричные фотографии услуг, светлая редакционная вставка, интерактивный подбор «Безопасность / Технологии / Комфорт / Внешний вид», цены-ориентиры, реальные направления и ссылки на работы сети, FAQ и карта;
- анимация: Motion for JavaScript как опциональное улучшение, безопасный fallback, reduced-motion;
- отдельная собственная страница /chizh-avto/, ничего не переиспользовано из других проектов кроме общих инфраструктурных подходов.

## Изображения
Используются **иллюстративные фотостоковые фотографии Unsplash**, загруженные с images.unsplash.com. Они НЕ показывают реальный филиал и НЕ являются фото указанных кейсов. Прямые изображения требуют сетевого доступа. Фактические фото центра/монтажа лучше заменить при согласовании с бизнесом. Условия лицензии стока проверять перед коммерческим использованием.

## Форма и пределы работы
Сайт — статический GitHub Pages. Встроенная форма **не отправляет заявку на сервер**, **не записывает клиента** и **не имеет CRM/онлайн-календаря**. При отправке клиент сам открывает почтовый клиент для письма на верифицированный адрес chizh-avto@mail.ru. Доступны прямой телефон и копирование текста обращения. Кнопки намеренно не имитируют успешную отправку.
Настоящий продакшен-сайт потребует согласования брендинга/фото/цен/персональных данных, авторизации собственника, реального backend для заявок, мониторинга, домена и юридических документов, если будет соответствующий сбор/обработка данных.
