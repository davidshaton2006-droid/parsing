## Установка и перенос
- При работе прямо в репозитории прочитать /AGENTS.md и /CLAUDE.md: они ведут к этому скиллу.
- Для другой системы передай целиком папку skills/shaton-client-site-factory (SKILL.md, references/TOOLKIT_AND_DESIGN_GATE.md и остальные references). Стандартно папку можно взять из ZIP всего репозитория: https://github.com/davidshaton2006-droid/parsing/archive/refs/heads/main.zip
- Если система поддерживает skills, размести папку в её каталоге skills и включи/упомяни по её правилам; универсального автозапуска во всех ИИ-продуктах не существует.
- Если система умеет читать только один файл, сначала передай SKILL.md, затем приложенные reference-файлы.
- Наличие скилла не даёт агенту автоматически GitHub-доступ: авторизация и права на запись должны быть предоставлены отдельно.
