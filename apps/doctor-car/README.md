# Доктор Кар — React/Vite, концепт №4, тёмная и светлая темы

Неофициальный демонстрационный сайт для автосервиса в Краснодаре. Вариант №4 утверждён пользователем до начала разработки; затем пользователь утвердил тёмный основной и светлый альтернативный интерфейс единой визуальной концепции.

## Дизайн

- Утверждённый вариант: «современный технологичный интерфейс», затем единая двухтемная версия.
- Палитра: фирменный чёрный и красный + нейтральные белый/серый. Голубоватые технические линии внутри авторской автомобильной схемы не меняют брендовый акцент.
- Скруглённые стеклянные поверхности, адаптивный header/menu, pointer-based Spotlight-свет для карточек, динамические рекомендации по симптомам, анимация узлов автомобиля.
- Источники проектирования изучены: jakubkrehel/skills; nextlevelbuilder/ui-ux-pro-max-skill; meta/astryx; motion.dev/docs; davila7/claude-code-templates; Aceternity UI/card-spotlight; 21st.dev/@jahed; 21st.dev.
- Spotlight — **собственная реализация визуального принципа**, не установка реестра Aceternity через CLI. Liquid navigation — собственная реализация по паттернам Jahed. Библиотеки Motion/react, React и Lucide устанавливаются через npm. Не утверждать, что другие библиотеки установлены без фактического подтверждения.
- Вся страница доступна без JavaScript по смысловому fallback в index.html (основные направления, адрес и телефон).

## Приложение

React 19 + Vite, Motion for React, Lucide. Дизайн рассчитан на GitHub Pages URL /parsing/doctor-car/. Маршруты в форме hash-navigation (#/services, #/work, #/prices, #/contact) не ломаются при прямой загрузке на статическом Pages.

Встроенные интерактивные функции: переключатель dark/light с запоминанием, техническая SVG-схема с кликабельными узлами, выбор неисправности, фильтры/поиск услуг, доступная форма подготовки обращения и копирования, прямой телефон, карта по клику, FAQ и мобильная навигация.

Команды: npm install, npm run dev, npm run build, npm run check, npm run test:e2e (для тестов нужен Playwright Chromium).

## Перед передачей реальному клиенту

Получить согласие владельца, подтвердить номер, график, услуги и цены, предоставить разрешённые фото/видео, согласовать фирменные материалы, подключить backend и документы обработки данных при реальном сборе заявок. Снять noindex только после согласования публичного запуска.
