# Чиж-Авто — React/Vite flagship demo

**Назначение:** неофициальный дизайн-концепт тюнинг-центра Чиж-Авто, Краснодар. Публикуется в **едином репозитории** `davidshaton2006-droid/parsing` по адресу `https://davidshaton2006-droid.github.io/parsing/chizh-avto/` после успешной сборки и QA. Прежние страницы GT Service, Альфа Авто, RIA-Service не изменяются.

## Технологии

- React 19 + Vite 6, отдельные компоненты и полноценная структура исходников, не монолитный HTML.
- Motion for React — анимации блоков, переходы, лёгкий параллакс; reduced motion учтён.
- Embla Carousel — галерея работ с реальным управлением и состояниями кнопок.
- Lucide React — интерфейсные иконки.
- CSS с компонентными секциями, адаптивными размерами и доступными состояниями.
- Чистые ссылки и изображения **только из официального домена** `chizhavto.ru`; видео — YouTube-материал компании, при недоступности есть переход в её канал.

## Содержание

Главная, каталог 12 направлений и подуслуг, фотографии и реальные проекты, прайс, о компании, отзывы, акции, контакты двух точек, официальные источники. Отдельный build-time sync строит каталог фактов по доступным страницам `chizhavto.ru`, сохраняет источники, прайс и кейсы. Если источник не ответил, сокращённый fallback **не выдаётся за полную копию**.

## Взаимодействия

Все навигационные ссылки, меню, поиск, раскрытие категорий, фильтры, галерея, видео, прайс, кнопки «Показать больше» и форма работают. В демо форма **не создаёт бронь и не отправляет данные на сервер**: подготовленный email пользователь отправляет из собственного почтового приложения, либо копирует текст, либо звонит напрямую. Реальный сервер заявок требует согласованного подключения и юридического оформления.

## Локальная разработка

```bash
npm install
npm run dev
npm run check:static
node scripts/factual-audit.mjs
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run sync:official` индексирует общедоступную информацию с оригинального сайта. Это может быть длительно; не обходите антибот/ограничения и не собирайте закрытые материалы. Соответствующая команда в CI имеет тайм-аут.

### Проверка публикации

GitHub Actions: `.github/workflows/deploy-pages.yml`. Деплой выполняется только если проект собрался и прошёл проверки. Предыдущая версия сайта остаётся публичной при неудачном CI. Последние версии материалов и контактов всегда уточняются на оригинальном сайте `https://chizhavto.ru/`.
