# ST CAR — утверждённый дизайн-концепт №1

**Статус:** неофициальное демо, утверждена визуальная концепция «Премиум и технологии» (19.11.2026). Публикация: https://davidshaton2006-droid.github.io/parsing/st-car/

## Дизайн
- Главная композиция: утверждённый графитово-красный визуальный стиль; крупный белый заголовок слева, реальная фотография фасада ST CAR справа, красные CTA, фирменный логотип из Яндекс Карт.
- Палитра: фон #090B0E, поверхности #11151B и #191F27, текст #F6F7FA, красный #E21F28, вторичный текст #9DA6B2.
- Manrope 400–800, широкая сетка 1220 px, контейнер 64/36/34 px в зависимости от ширины экрана; адаптация под мобильные.
- Desktop: фиксируемый верхний навбар, большой hero, четыре быстрых направления, 8 основных карточек услуг и 12 дополнительных направлений, путь обращения, подтверждённые отзывы, фото фасада и рабочих боксов, FAQ, интерактивную карту и контакты.
- Mobile: сокращённая hero-композиция, гамбургер, двухколоночные shortcuts, одно-колоночные услуги, фиксированное нижнее меню звонка/обращения.
- Основной пользовательский сценарий: выбор услуги → описание проблемы → копирование текста для разговора с сервисом либо звонок.
- Интерактив: фильтрация услуг, быстрые переходы, модальный dialog, подготовка текста, копирование с fallback, мобильная навигация; мягкие анимации Motion for JavaScript по CDN с безопасным fallback.
- Контент на странице виден и доступен при выключенном JS, кроме интерактивных действий. prefers-reduced-motion учитывается.

## Улучшение от 19.11.2026: навигатор по симптомам
- В существующую утверждённую концепцию №1 добавлен интерактивный блок `#symptoms` с шестью симптомами: Check Engine, стуки подвески, увод с прямой, проблемы электрики, шум тормозов и плановое ТО.
- Рекомендации являются информационными, не подменяют диагностику и не выдают точных диагнозов, цен либо готовой записи.
- Выбор переключает описание и категорию, формирует контекстное обращение через уже существующий диалог; кнопка «Подробнее» сбрасывает фильтр услуг и переводит к нужной карточке.
- Результат работает без новых JS-зависимостей: `experience.js` и `experience.css` добавлены отдельно, чтобы избежать дальнейшего разрастания монолитной страницы.
- Фотография в секции процесса теперь загружается как обычное изображение с `loading=lazy`, вместо фонового CSS-запроса при загрузке страницы.
- В Playwright добавлены сценарии по переключению симптомов, передаче услуги в форму, сбросу фильтров и проверке дополнительного диапазона ширин.
- Для коммерческого использования по-прежнему нужны разрешения на материалы и согласованный способ реальной отправки заявок.

## Ограничения и QA
- GitHub Pages — статический хостинг: форма готовит текст, но **не отправляет заявку** и не бронирует время; персональные данные не уходят на сервер.
- Внешние изображения/шрифты/Motion требуют сети, без них интерфейс и контент сохраняются.
- Минимальная проверка исходников: секции/якоря, явные контакты, 8 сервисных карточек и 12 дополнительных направлений, нулевые скрытые SEO-блоки, CSS reduced motion, aria labels и сообщения формы.
- Полноценную визуальную и браузерную QA-проверку на viewport 320/375/390/768/1024/1440, загрузку внешних изображений и доступность публичного URL нужно подтверждать отдельно; статический анализ не является доказательством.

## Доработки профессиональной версии (19.11.2026)
- В утверждённой графитово-красной гамме сохранён премиальный первый экран и реализован более конкретный контент о ST CAR.
- В галерее три изображения реального автосервиса (фасад, внешний вид, ремонтная зона). При ошибке загрузки основного кадра hero предусмотрена замена на подтверждённую фотографию фасада. Изображения загружаются с серверов Яндекса, не скопированы в репозиторий.
- Услуги дополнены 12 направлениями из характеристик карточки Яндекс Карт. Кнопки открывают запрос с заполненным видом услуги. Цены, длительность и доступность не выдуманы.
- Рейтинг 5,0 / более 450 оценок зафиксирован по публичной карточке; это значение может меняться, поэтому перед официальной публикацией требуется повторная проверка или динамическая интеграция.
- Playwright-тесты находятся в `apps/chizh-avto/tests/stcar.spec.js`, покрывают работу фильтра, формы, 20 направлений, мобильной навигации, скриншоты, отсутствие горизонтального скролла, режим без JS и подгрузку карты по запросу.
- Статически проверены JavaScript, уникальность id, существование якорей и корректность контактных данных. Запуск браузерного CI и фактическая работоспособность GitHub Pages **не подтверждены** по доступным инструментам на момент этого изменения.
- Для коммерческой публикации нужно согласие компании на используемые фотографии/бренд и подключение подтверждённого канала приёма заявок.
